# Operating Systems Virtual Machine Coursework

A collection of C++ and Linux-based operating systems exercises covering process management, memory management, scheduling, file systems, networking, synchronization, and security.

## What This Repository Demonstrates

The coursework is organized as a series of practical tasks:

| Task / Component | Topic |
| --- | --- |
| Task 1 | Unix-style shell / process interaction |
| Task 2 | Multithreading with POSIX threads and word counting |
| Task 3 | Aging-based paging / memory management |
| Task 4 | Deadlock handling |
| Task 5 | CPU scheduling |
| Task 6 | File-system related processing and histogram generation |
| Task 7 | TCP client/server chat |
| Task 8 | DES-based password/security exercise |

Additional files provide input data, setup scripts, and supporting implementations.

## Tech Stack

- C++
- Linux / POSIX APIs
- POSIX Threads (`pthread`)
- TCP sockets
- Shell scripting
- Git / GitHub Codespaces

## Development Environment

The repository includes configuration for a containerized Linux development environment. It can be opened in GitHub Codespaces or another compatible development-container environment.

## Why This Project Matters

Rather than only implementing isolated algorithms, these exercises demonstrate practical systems programming concepts including concurrency, synchronization, memory management, scheduling, networking, and operating-system behaviour.

## Academic Context

University operating systems coursework implemented and tested in a Linux environment.
